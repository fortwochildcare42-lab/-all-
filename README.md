# 🎓 English Master ── 高校英語 Zoom レッスン教材

## プロジェクト概要

高校1年生（三重県）を対象とした、毎週金曜日 Zoom 1時間レッスン専用の英語教材サイトです。全12回・4学習期のカリキュラムに対応し、各レッスンが約60分でこなせるボリュームで設計されています。

---

## ✅ 実装済み機能

### 全レッスン共通
- **学習タイマー**：レッスン開始からの経過時間をリアルタイム表示
- **進捗バー**：全12回中の現在地をビジュアル表示
- **解答・解説ボタン**：クリックで正解と詳細解説を表示/非表示
- **採点ボタン**：選択問題の正答数と正答率を表示
- **空所補充のリアルタイム判定**：入力と同時に○✕をビジュアル表示
- **模範解答の表示/非表示**：英作文の参考として活用
- **レッスン間ナビゲーション**：前後のレッスンへワンクリック移動
- **スクロールトップボタン**：300px スクロール後に表示

### 各レッスンのコンテンツ構造
1. **文法解説**（表・例文・ポイントボックス付き）
2. **選択問題**（MCQ 4〜8問）
3. **空所補充問題**（fill-in-the-blank 3〜5問）
4. **並べ替え問題**（語句整序）
5. **長文読解**（150〜250語の英文 + 読解問題）
6. **英作文チャレンジ**（条件付き英作 + 模範解答）

## 🚀 使い方

1. `index.html` を開いてメインメニューを表示
2. 受講したいレッスンをクリック
3. 文法解説 → 練習問題 → 長文 → 英作文の順に進める
4. 英作文は Zoom チャットまたは口頭で発表
